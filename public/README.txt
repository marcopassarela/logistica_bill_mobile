COMO COLOCAR A LOGO
===================

1. Coloque o arquivo da sua logo nesta pasta com o nome EXATO:

   logo.png

2. Formatos aceitos: PNG (recomendado), ou use logo.png convertido.
   Tamanho ideal: 200x200 px ou 512x512 px (quadrado).
   Fundo transparente fica melhor.

3. Reinicie o npm run dev (ou faça deploy de novo na Vercel).

A logo aparece:
- No menu lateral (sidebar)
- Se o arquivo não existir, mostra "LB" automaticamente.

Também pode usar na tela de login substituindo o bloco "LB".
